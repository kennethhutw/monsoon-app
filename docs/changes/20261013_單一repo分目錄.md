# 20261013_單一repo分目錄

## 變更摘要
Metropolis hackathon 要求單一 repo。把原本分開的 `monsoon-app` 與 `monsoon-contract` 合併成同一個 repo（沿用 `kennethhutw/monsoon-app`），分成 `/app`、`/contracts` 與根目錄 `README.md`。

## 變更內容
- 用 `git mv` 把 App 的所有已追蹤檔案移進 `/app`（保留 git 歷史）；原本 App 內的 Next.js `app/` 資料夾因此會變成 `/app/app/`，這是預期結果
- 把 `monsoon-contract` 的內容（不含 `.git`、`node_modules`、`.env`）複製到 `/contracts`
- 新增根目錄 `README.md`（專案總覽、目錄結構、合約地址、連結）；原本的 App README 移到 `/app/README.md`
- `/app/README.md` 與 `/contracts/README.md` 內的跨 repo 連結改成相對路徑
- Vercel 專案設定 Root Directory 改為 `app`
- 本機 `.env.local`（未追蹤）一併移到 `/app`

## 影響範圍
- repo 內所有檔案路徑多一層 `app/`；`CLAUDE.md`、`docs/DESIGN.md`、`docs/changes/` 這些受保護檔案隨資料夾一起搬移，**內容不變**（Kenneth 明確決定）
- Vercel 部署設定（Root Directory）
- 舊的獨立合約 repo `kennethhutw/monsoon-contract` 不再維護，保留不刪除，README 註明已併入

## 對應 PRD 章節
- 不對應 `Monsoon_App_PRD.md`，屬於 repo 結構調整

## 決策依據
- 主辦方要求提交單一 repo；沿用 `monsoon-app` 可以保留現有 GitHub 連結與 Vercel 連動，只需改 Root Directory
- 用 `git mv` 保留檔案歷史，不重建 repo
